# [UND-77] 고정폭 서체 열거

> wave 9 · 사이즈 S · 의존 UND-68 · 소유 `domain/typography/` · `infrastructure/typography/`

## 작업 내용 (설계 의도)

설정 화면이 **설치된 고정폭 서체 목록**을 제시할 수 있어야 한다. 지금은 이름을 직접 입력해야 하고,
오타를 내면 조용히 시스템 기본으로 떨어진다.

열거는 **infrastructure 가 한다** — `java.awt.GraphicsEnvironment` 는 플랫폼 API 이고, presentation
에서 직접 부르면 화면이 플랫폼에 묶인다.

**고정폭만 거른다.** 전체 서체 목록은 수백 개라 고르기 어렵고, 이 설정의 대상은 diff·코드 표시다.

목록 조회는 **느릴 수 있다** — 첫 조회 결과를 재사용하고, 조회 중임을 화면이 알 수 있게 한다.

**롤백**: 읽기 전용 계약 추가라 revert 로 끝난다.

## 테스트 케이스

- 열거 결과에 시스템의 고정폭 서체가 포함된다
- 비고정폭 서체는 결과에 없다
- 저장된 서체 이름이 목록에 없어도 그 값이 지워지지 않는다
- 열거가 실패해도 화면이 이름 직접 입력으로 동작한다
