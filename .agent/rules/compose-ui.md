# Compose Desktop UI 규칙

1. **상태는 끌어올린다.** Composable 내부 `remember` 에 비즈니스 상태를 두지 않는다.
   화면 상태는 상태 홀더가 소유하고 Composable 은 인자로 받는다.
2. **Composable 은 부수효과를 직접 일으키지 않는다.** I/O 는 `LaunchedEffect` 또는 상태 홀더의 코루틴에서.
3. **리스트는 `LazyColumn` 에 `key` 를 준다.** 커밋 목록처럼 수만 건인 화면에서 key 가 없으면
   스크롤 시 전체가 재구성된다. key 는 커밋 해시처럼 안정적인 값이어야 한다.
4. **무거운 계산은 `remember(key)` 로 캐시한다.** 그래프 레인 배치를 매 프레임 다시 계산하지 않는다.
5. **테마 값은 하드코딩하지 않는다.** 색·간격·타이포는 디자인 토큰을 통해서만 참조한다 —
   라이트/다크 전환이 한 곳에서 끝나야 한다.
6. **`Modifier` 는 첫 번째 선택 파라미터로 받는다.** 호출부가 레이아웃을 제어할 수 있어야 한다.
7. **긴 작업에는 진행 상태를 노출한다.** fetch·clone 처럼 초 단위 작업이 무반응으로 보이면 안 된다.
8. **키보드 조작 경로를 남긴다.** 주요 동작은 마우스 전용이 아니어야 한다.
